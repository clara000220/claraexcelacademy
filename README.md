# Clara Excel Academy

Marketing + course-catalog website for **Clara Tan Chai Fang**, HRDC-accredited Excel & AI trainer in Malaysia.

Live site: deployed via Vercel from this repo.

## Stack

Plain static HTML — no build step. Drop `index.html` and the logo onto any static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages) and it works.

## Files

- [`index.html`](index.html) — full single-page site (hero, courses, about, features, corporate, testimonials, FAQ, contact, footer, sticky WhatsApp)
- `Clara Excel Acadmey logo.png` — main brand logo (filename keeps the original spelling for backwards compatibility)

## Editing the site

The whole site is in [`index.html`](index.html). Open in any text editor (VS Code, Notepad++), change prices/copy/links, save, and push:

```
git add index.html
git commit -m "Update course prices"
git push
```

Vercel will auto-deploy within ~30 seconds.

## Local preview

Just double-click `index.html` — opens in your default browser. No server required.
